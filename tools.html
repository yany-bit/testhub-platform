工具形态平台上的打开方式
JMeter / Katalon / Apifox / Bruno桌面应用程序（需安装 Java / 独立客户端）浏览器不允许网页直接启动本地 .exe（避免恶意网页调用本机程序），因此按钮直达官网下载页，安装后从开始菜单启动
LocustPython 库，命令行启动按钮直达官网与 PyPI 安装页，pip install locust 后用 locust 命令启动 Web 管理界面
AngusTesterSaaS 云平台纯在线服务，提供 GM 工作台（登录）、测试控制台（项目/用例/执行）、AngusAI 对话三个直达入口，无需安装
JSONPlaceholder公开 REST 接口服务接口测试页的「在线接口测试台」可直接对其发送真实请求
