代码案例：一个折扣函数，LLM 自动生成了什么测试？

核心方法 —— 以 calculate_discount 为例，LLM 覆盖了正常折扣计算、零价格异常、未知等级异常

被测函数（输入给 LLM 的源码）
def calculate_discount(price, level):
    if price <= 0:
        raise ValueError("价格必须大于0")
    if level == "VIP":
        return price * 0.8
    elif level == "普通":
        return price * 0.95
    else:
        raise ValueError("未知等级")
LLM 自动生成的测试代码
def test_vip_discount():
    assert calculate_discount(100, "VIP") == 80.0

def test_normal_discount():
    assert calculate_discount(200, "普通") == 190.0

def test_zero_price_error():
    with pytest.raises(ValueError):
        calculate_discount(0, "VIP")

def test_unknown_level_error():
    with pytest.raises(ValueError):
        calculate_discount(100, "钻石")
